# HTTPal

HTTPal is a simple Go command-line tool.  
It sends an HTTP request to a website and prints the response.

## How to run it

```bash
go run . -url [https://example.com](https://example.com)
```
## How it works

1. Read the URL from the command line
2. Create an HTTP request
3. Send the request
4. Read the response
5. Print the response
